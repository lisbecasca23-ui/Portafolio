Caso de estudio 01

Hotel Beach.SA

Un sistema completo de reservas hoteleras, construido como proyecto de Programación de Aplicaciones Comerciales. Cubre desde la reserva del huésped hasta la factura final, sin intervención manual.

Sistema de reservas con facturación automática

ASP.NET Core Web API + MVC · .NET 8
C# / .NET 8 Entity Framework JWT Auth iTextSharp (PDF) API BCCR

Qué resuelve

Un huésped reserva una habitación, el sistema calcula el monto, lo convierte automáticamente entre colones y dólares con el tipo de cambio oficial del día, genera la factura en PDF y la envía por correo — todo sin que el personal del hotel tenga que hacer cálculos ni redactar nada a mano.

Funcionalidades clave

  • Autenticación segura de usuariosJWT ✓
  • Gestión de reservas y disponibilidad✓
  • Conversión de moneda en tiempo realBCCR ✓
  • Generación automática de facturasPDF ✓
  • Notificaciones por correo al huésped✓
  • Panel administrativo separado del cliente✓

De reservas a menús

El sistema de Hotel Beach.SA y un menú interactivo de restaurante comparten la misma base técnica — solo cambia el contenido.
